# Getting help with Burn & Claim

- **Questions about Burn & Claim:** Email [support@burnandclaim.com](mailto:support@burnandclaim.com).
- **A bug in a repository here:** open an issue in that repository, with the steps to reproduce it.
- **A security problem:** never in an issue. See [SECURITY.md](SECURITY.md).

Issues are for bugs and concrete feature requests in the code here, not for help with an account.
