# Burn & Claim

your Solana wallet is full of stuff you'll never use.\
empty token accounts. tokens and NFTs you stopped caring about.

each one holds SOL as rent.\
burn & claim closes the empty accounts, burns what you don't want, and gives that SOL back.\
no custody. you sign every transaction.

try it → [burnandclaim.com](https://burnandclaim.com) · [@burnandclaim](https://x.com/burnandclaim)
